🏥 Hospital Management System

📖 Overview
The Hospital Management System is a Java-based desktop application built to simplify and automate hospital administrative tasks.  
It efficiently manages patients, doctors, receptionists, and appointments through an interactive graphical interface.  
The system was developed using **Java Swing**, **MySQL**, and **NetBeans IDE** — combining simplicity, speed, and database reliability.

---

✨ Features

👨‍⚕️ Admin Module
- Manage doctors, receptionists, and hospital staff  
- View and edit patient records  
- Monitor hospital data efficiently  

💁 Receptionist Module
- Register new patients and manage details  
- Schedule, update, and cancel appointments  
- Maintain patient visit history  

🧑‍⚕️ Doctor Module
- View patient details and medical history  
- Add diagnosis and treatment updates  
- Track appointments assigned to them  

💾 Database Integration
- Integrated with **MySQL** for data storage  
- Includes `hospital.sql` for easy setup  
- Real-time CRUD (Create, Read, Update, Delete) operations
